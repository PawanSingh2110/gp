============================================================
4. STEP-BY-STEP PROCEDURE
============================================================

STEP 1 — Create a 2D project
1. Open Unity Hub.
2. Create or open a 2D Core project.
3. Open the scene.
4. Save the scene (Ctrl+S).

STEP 2 — Create the Player
1. In the Hierarchy, right-click.
2. Choose 2D Object > Sprites > Square (the exact menu wording can vary by Unity version).
3. Rename the object to: Player
4. Select Player and set its Transform Position to approximately:
   X = 0, Y = 0, Z = 0
5. Add a Rigidbody 2D component:
   Inspector > Add Component > Rigidbody 2D
6. Set Gravity Scale = 0 so the player does not fall due to gravity.
7. Add a Box Collider 2D:
   Inspector > Add Component > Box Collider 2D
8. Ensure Box Collider 2D > Is Trigger is UNCHECKED.

STEP 3 — Create the Wall
1. In the Hierarchy, right-click.
2. Choose 2D Object > Sprites > Square.
3. Rename it to: wall (lowercase, matching the user's current object name).
4. Set Transform approximately:
   Position: X = 3, Y = 0, Z = 0
   Scale: X = 1, Y = 5, Z = 1
5. Add a Box Collider 2D if one is not already present.
6. Ensure Is Trigger is UNCHECKED.

STEP 4 — Create the movement script
1. In the Project window, open the Assets folder.
2. Right-click > Create > monobehaviour > C# Script.
3. Name it exactly: PlayerMovement
   (Unity creates PlayerMovement.cs; the file name should match the public class name.)
4. Double-click it and replace all contents with the code below.
5. Save the script (Ctrl+S).
6. Return to Unity and wait for script compilation to finish.
7. Drag PlayerMovement.cs onto Player in the Hierarchy, or select Player and use Add Component > PlayerMovement.
8. Confirm the script appears in Player's Inspector.

============================================================
5. COMPLETE WORKING CODE
============================================================

using UnityEngine;

public class PlayerMovement : MonoBehaviour
{
    public float speed = 5f;

    private Rigidbody2D rb;
    private Vector2 movement;

    void Start()
    {
        rb = GetComponent<Rigidbody2D>();
    }

    void Update()
    {
        float x = Input.GetAxisRaw("Horizontal");
        float y = Input.GetAxisRaw("Vertical");

        movement = new Vector2(x, y).normalized;
    }

    void FixedUpdate()
    {
        rb.MovePosition(
            rb.position + movement * speed * Time.fixedDeltaTime
        );
    }

    void OnCollisionEnter2D(Collision2D collision)
    {
        Debug.Log("Collision with: " + collision.gameObject.name);

        if (collision.gameObject.name == "wall")
        {
            Debug.Log("Player hit the wall!");
        }
    }
}
